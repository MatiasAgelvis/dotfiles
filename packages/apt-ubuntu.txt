# Ubuntu system packages for the homelab server.
#
# This file is repo-internal (not stowed): it is an input for
# bootstrap/linux.sh, not a file that must live at a $HOME path.
#
# Refresh from the real machine:
#   apt-mark showmanual | sort > packages/apt-ubuntu.txt
#
# Restore on a fresh box:
#   sudo apt-get install -y $(grep -vE '^[[:space:]]*(#|$)' packages/apt-ubuntu.txt)
#
# Caveats:
#   - `apt-mark showmanual` also lists whatever the base image preseeded
#     (kernel headers, cloud-init, snap tooling). Prune those by hand.
#   - Package names drift between releases: libssl3 -> libssl3t64 in 24.04.
#     Record the release this was captured on.
#
# Captured on: Ubuntu 26.04.1 LTS (resolute)
